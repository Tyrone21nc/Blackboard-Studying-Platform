# Blackboard-Studying-Platform

### To run
1. create a virtual environment in the main directory. These commands can get them done.
   1. On Mac: Run this: <code>python3 -m venv venv</code>, then: <code>source venv/bin/activate</code>
   2. On Windows: Run this: <code>python -m venv venv</code>, then: <code>source venv/bin/activate</code>
   3. After either command, kill the terminal (run the command: <code>exit</code>) and reopen it (go to view then terminal or Ctrl + ` (backtick) or Command + backtick same as for Ctrl), you should see ((venv))
2. Then download some other necessary software: <code>pip install django djangorestframework google-genai python-dotenv</code>
